RAG Systems

Retrieval-Augmented Generation combines external retrieval with language generation.

Chunking

Chunking divides documents into smaller retrievable units.

Recursive Chunking

Recursive chunking tries larger boundaries first and moves to smaller boundaries when necessary.

Token Chunking

Token chunking controls chunk size using tokenizer tokens.

Vector Databases

Vector databases store embeddings and support similarity search.
